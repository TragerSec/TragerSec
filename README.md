<h3>⚔️ About me</h3>

<p>I'm an Offensive Security Engineer with <strong>4+ years of pentesting experience</strong>. Most of my work involves infrastructure, Active Directory, web applications, and AI/LLM services. I also work on vulnerability management and automate the repetitive parts of security testing.</p>

<p>I hold a <strong>BSc in Information Security (Computer Systems Security)</strong> from SPbSUT.</p>

<p>From 2021 to 2025, I competed with my university's CTF team in regional and international events. I also placed <strong>6th and 9th</strong> in enterprise-level cyber range competitions in 2025-2026.</p>

<p>Outside work, I work through Hack The Box labs, build side projects, and explore new areas of security. I test ideas in my home lab, publish <a href="https://notes.hackandgtfo.xyz/hackthebox-writeups/contents">HTB write-ups</a> and security research, and keep my notes and playbooks in Obsidian.</p>

<h3>🎯 What I do</h3>

<p>I offer <strong>external and internal penetration testing</strong>, vulnerability assessments, and security automation:</p>

<ul>
  <li><strong>AI &amp; LLM security:</strong> assessments of AI-powered applications, LLM services, and integrations.</li>
  <li><strong>ICS/OT security:</strong> industrial security audits, network exposure assessments, and configuration reviews.</li>
  <li><strong>Infrastructure, networks &amp; Active Directory:</strong> network and service testing, AD attack path analysis, and checks for privilege escalation and misconfigurations.</li>
  <li><strong>Mobile application security:</strong> static and dynamic analysis, runtime testing, and backend API assessments.</li>
  <li><strong>Security automation:</strong> VM/DAST pipelines, MCP servers, scanning, and reporting with Python, Bash, and PowerShell.</li>
  <li><strong>Social engineering:</strong> phishing and vishing simulations to assess security awareness and incident response.</li>
  <li><strong>Vulnerability assessment &amp; management:</strong> validation of findings, risk prioritization, remediation guidance, and VM workflow design.</li>
  <li><strong>Web applications, APIs &amp; SaaS:</strong> testing authentication, access control, business logic, and service integrations.</li>
  <li><strong>Wi-Fi &amp; wireless security:</strong> testing wireless authentication, access controls, and configurations.</li>
</ul>

<p><sub>Additional work: CVE-based PoCs and tools for exploit collection and analysis.</sub></p>
